Site oficial (local, não publicado)

Site estático (HTML/CSS/JS puro, sem rede, sem cookies, sem rastreadores). Saída em site/public/. Nada foi publicado, nenhuma conta ou hospedagem foi criada. Nome do jogo = nome de trabalho (Ragna Tale).

Gerar e ver

``bash python tools/site/build_site.py # tudo: Codex público + páginas do site python tools/site/build_site.py --no-codex # só as páginas do site (rápido) python tools/site/build_site.py --serve # gera e serve em http://localhost:8913 ` No Claude Code: preview_start com a configuração site-local (.claude/launch.json`). Requer Python com Pillow.

Configuração central

tools/site/config.py: GAME_NAME (nome), DOMAIN, CONTACT_EMAIL, INDEXABLE (noindex enquanto False), paleta (da bíblia de arte), menu, tribos, linhas de classe e pilares. Trocar o nome = editar GAME_NAME e regerar; o nome é substituído também nas páginas do Codex e nos rascunhos legais.

Páginas

Início, Mundo e classes, Bestiário, NPCs, Notícias (1 entrada de exemplo marcada), Termos e Privacidade (de docs/legal/*-draft.md, com aviso "rascunho, requer advogado"), Contato (placeholder). A lista de espera é um formulário desativado que não envia nem coleta nada.

Como o Codex sincroniza

build_site.py roda tools/codex/make_web.py (PNG -> WebP) e tools/codex/build_codex.py <parte> --public para mundo, bestiario e npcs; o modo --public tira prompts de imagem, ferramentas do criador (alturas, "Atualizar") e a aba de documentos internos (anti-cheat, sanções etc.). O HTML vai para site/public/<parte>/ com a barra e a paleta do site. Não há mais limite de 511 arquivos. O Artifact do Codex continua gerável pelo pipeline antigo (build_codex.py, stage.py). Regra do CLAUDE.md: a cada mudança de conteúdo, regerar o site e republicar os Artifacts.

Git: o gerador e as páginas pequenas vão ao git; site/public/img/, bestiario/, npcs/, mundo/ e site/codex/parts_public/ ficam no .gitignore (pesados, regeneráveis).

Central (página única e privada)

python tools/site/central.py gera uma página só com abas Início, Bestiário, NPCs, Mundo e classes (mapas, zonas, classes, equipamentos e ícones) e EAP (de docs/EAP-progresso.json), com tema claro/escuro, celular, "↻ Atualizar" e carimbo de geração. Usa as funções de parse de tools/codex/build_codex.py só para leitura (não altera o Codex). Conteúdo sem prompts de imagem nem documentos internos. É página do criador: a EAP nunca vai para o site público.

Imagens: WebP ~800 px q80 (reduções das existentes, nada novo é criado), miniaturas 360 px na grade e lightbox próprio (zoom por roda/pinça/botões, arrasto, duplo clique, Esc) sem biblioteca.

  • Saída 1 site/public/central/ (index.html + img/m médio, img/t miniatura, img/f resolução cheia usada no zoom). Sem limite de arquivos (~1.780 arquivos; as cheias são hardlinks). Ver: preview_start com central-local (porta 8915).
  • Saída 2 site/dist/central/ (fragmento para Artifact): 458 arquivos, 19,8 MB (limite 505 e 60 MB; Artifact aceita 511 por versão). 198 monstros e 166 NPCs individuais; 24 mapas de zona, 1 vila, 51 folhas e molduras de equipamento individuais; 12 mosaicos de classe (72 imagens, uma folha por linha) e 1 mosaico de ícones 128 px (230 ícones) recortados por CSS background-position (e por canvas no zoom). O gerador sai com erro se passar de 505 arquivos ou 60 MB. Zoom no Artifact usa o médio (sem cheia).
  • Publicar: Artifact privado em 2 publicações sequenciais para a mesma URL (máx. 255 arquivos por publicação; lista de img/ em ordem alfabética, index.html junto). URL atual no CLAUDE.md. Git: site/public/central/ e site/dist/central/ são regeneráveis (.gitignore).
  • Fora: aba de itens e cartas (fichas), documentos Markdown e galeria geral do Codex; alturas e prompts (ferramentas do criador).
  • EAP: tools/eap/gen_eap.py está defasado em relação a docs/EAP-progresso.json (gera 38,3% contra 39,2% do JSON atual); não foi rodado. A Central lê o JSON como está.

Site público no GitHub Pages (temporário, recorte MVP)

URL: https://pio1942.github.io/ragnatale-site/ (repositório público pio1942/ragnatale-site, só o pacote; o repositório do jogo não é enviado). Autorizado pelo criador em 2026-11-08 (docs/DECISIONS.md). Nome de trabalho; noindex mantido.

  • Regerar o pacote: python tools/site/publish_pages.py (saída em site/public_gh/, no .gitignore do jogo, com .git próprio).
  • Republicar: python tools/site/publish_pages.py --push (regera, roda a varredura de segurança, comita no repositório do site e dá push; o Pages reconstrói sozinho). Só --check roda a varredura sem enviar. O .git do pacote usa o e-mail noreply do GitHub (nunca o e-mail pessoal).
  • Recorte: monstros até o nível 50 (92), zonas com faixa até 50 (Sopé das Cinzas cortado em 50), NPCs das vilas e acampamentos até 50 (67), classes só com as formas 1-3 (níveis 1, 20, 40) e "mais evoluções no futuro". Sem: EAP, documentos, prompts, vida/ataque/defesa/XP/ouro, taxas de drop, mapa-múndi (mostra o mundo todo) e chefes finais. Drops aparecem só por nome.
  • Imagens: WebP até 900 px (zoom por clique) e miniaturas de 360 px; cartões de pré-visualização img/og/*.jpg (1200x630) para o WhatsApp.
  • Tamanho: ~19 MB, ~880 arquivos (limite do Pages ~1 GB).
  • Primeira publicação (já feita): gh repo create pio1942/ragnatale-site --public, git init em site/public_gh, push em main, gh api -X POST repos/pio1942/ragnatale-site/pages -f 'source[branch]=main' -f 'source[path]=/'.
